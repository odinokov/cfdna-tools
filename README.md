# cfDNA Tools

A searchable catalog of computational tools for **cfDNA / ctDNA** liquid-biopsy
analysis — fragmentomics, methylation, copy-number, end motifs, coverage/WPS,
and tissue-of-origin workflows.

## What's inside

Each row is one tool with repo/paper links, inputs, outputs, install method, and
capability flags across eight axes: fragment size, end motifs, coverage/WPS,
methylation, SNV/CNA, region-level, tissue origin, and GC/bias.

| Flag | Meaning |
|------|---------|
| ✅ | Native support |
| 🟡 | Partial / wrapper / limited |
| ❌ | Not supported |
| ❓ | Unclear from public docs |
